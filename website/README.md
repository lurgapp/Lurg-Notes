# Страница Lurg Notes

Здесь исходники продуктовой страницы из `frontend/app/notes/page.tsx`, её общих компонентов и стилей. Для отдельного проекта страница перенесена в `app/page.tsx`; конфигурация Next.js больше не требует родительский монорепозиторий. Общее оформление, SEO и ссылки на публичные продукты сохранены.

```bash
npm ci
npm run dev
# http://localhost:3000
npm run build
npm start
```

Нужен Node.js 22. `package.json` и lockfile сохранены из исходного frontend, включая его общий набор зависимостей. Эта папка содержит страницу продукта; веб-редактора заметок в текущем продукте нет. Ссылки на загрузку APK, Lurg ID и документацию ведут на публичные домены Lurg.
