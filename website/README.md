# Страница Lurg Notes

Продуктовая страница на Next.js с общими компонентами, оформлением и SEO Lurg. Это самостоятельный проект с корневым маршрутом в `app/page.tsx`.

```bash
npm ci
npm run dev
# http://localhost:3000
npm run build
npm start
```

Нужен Node.js 22. Эта папка содержит страницу продукта; веб-редактора заметок в текущем продукте нет. Ссылки на загрузку APK, Lurg ID и документацию ведут на публичные домены Lurg.
