# Состав публичного экспорта

Снимок исходников подготовлен 14 октября 2026 года из рабочего дерева Lurg. Он включает незакоммиченные исходники, существовавшие в момент экспорта, а не только файлы последнего Git-коммита. Полный список файлов и их SHA256 находится в `../SOURCE_MANIFEST.json`.

## Соответствие исходникам

| Публичный путь | Источник |
| --- | --- |
| `android/` | `mobile-notes/android/` без локальных ключей, Firebase-конфигурации, SDK-настроек и сборок. |
| `server/` | Notes и замыкание общих зависимостей из `backend/`, исходная схема SQL, вся цепочка Alembic, зависимости и связанные тесты. |
| `lcp/` | Исходники общего шлюза LCP и тесты. |
| `website/` | Страница `frontend/app/notes/page.tsx`, layout, общие стили, компоненты, SEO, favicon и конфигурация зависимостей frontend. |
| `docs/` | `docs/LURG_NOTES.md`, `docs/lurg-notes-e2ee-v2.md` и инструкции публичной копии. |

## Адаптации

- Android сохраняет подготовленную Grok конфигурацию: Firebase-плагин подключается при наличии собственной конфигурации, debug-подпись создаётся локально, release-подпись берётся из внешнего файла или окружения.
- Серверный `app/main.py` подключает необходимые Notes маршруты и фоновые процессы. Общие Graph/AI/identity-реализации сохранены, включая функции из chat-модуля; chat HTTP API не подключён. Личный адрес владельца из настроек заменён пустым значением, приложением авторизации по умолчанию выбран `lurg_notes`.
- Полная цепочка миграций сохранена вместе со схемой: отдельные Notes-ревизии не могут применяться без предыдущих платформенных ревизий. Добавлен инициализатор, который отказывается работать с непустой схемой.
- Продуктовая страница перенесена в корневой маршрут отдельного Next.js-проекта. Production tracing ограничен этой папкой.
- Один LCP-тест обращался к файлу в локальном `artifacts/`. Исходный минимальный producer сохранён в `lcp/tests/fixtures/nearby_lcp_events.py`, тест теперь использует этот относительный путь. Рабочие данные Nearby не копировались.
- В описании Notes исправлены ссылка на E2EE и устаревшее утверждение об отсутствии LCP: текущий foreground-клиент получает invalidation и загружает изменения через HTTP.
- Добавлены инструкции запуска, локальный Compose, пустые примеры окружения и проверка экспорта.

Поля `kind` в manifest: `copied` — побайтовая копия; `adapted` — файл с изменениями для публичной структуры; `generated` — добавленный файл. `source` указывает путь внутри исходного рабочего дерева и полезен для аудита происхождения; для использования публичного репозитория это дерево не требуется.

## Исключения

Включены только компоненты текущей версии. Прежняя оболочка Expo, неиспользуемый compatibility plugin и дизайн-концепты не входят в экспорт.

Не включены `.env` и рабочие секреты, Firebase service account и настоящий `google-services.json`, keystore/signing.properties, local.properties, базы и резервные копии, node_modules, виртуальные окружения, APK/AAB, кеши и материалы тестовых прогонов. Административные интерфейсы, операции, поддержка, другие приложения и production-конфигурация сервера не экспортированы. Общие таблицы и небольшие вспомогательные модули остаются там, где Notes зависит от них.

Папка не содержит историю исходного Git-репозитория. Публикация выполняется как первый коммит отдельного репозитория по инструкции `../GITHUB.md`.
